# Ext2 页填充统一：EOF 外页面清零

由 OpenAI Codex 生成。

`ext2_readpage(page)` 现在调用 `ext2_readpages(&page, 1)`。
多页接口不再拒绝 EOF 外的页；仍保留页数组内部约定及可表示页号的检查。
文件范围内读取已映射块，空洞及 EOF 之后的部分填零。
页缓存面向普通读取的 EOF 检查保持不变，文件大小也不在此处更新。
全零页仍由调用者在成功返回后标记 Uptodate。

## 实际测试结果

复用 `test/fs/ext2_readpages_test.c`，按之前记录的交叉编译及用户态 QEMU 命令运行。
实际输出：`ext2-readpages-test: PASS`。内核编译链接通过。

| 用例 | 实际结果 |
| --- | --- |
| 空文件，单页入口请求第 0 页 | 整页为零，零次块映射查询，零次 BIO 提交 |

| 文件只有 17 B，单页入口读取 | 前 17 B 为模拟磁盘内容，剩余部分为零 |
| 同批包含文件内页和 EOF 外页 | 文件内正常读取，EOF 外页全部为零 |
| 原有合并、分批、空洞及失败测试 | 通过 |

测试队列显式设置 max_hw_sectors=256，适配当前代码要求非零上限的约定；
不恢复此前的“零表示未指定限制”处理。
模拟提交接口校验分区范围，越界块由该接口返回 EIO；不代表 Ext2 当前仍保留该校验。
